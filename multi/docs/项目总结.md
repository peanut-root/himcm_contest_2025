## 🎓 技术亮点

### 1. 图论建模
- 使用 `graphology` 库构建建筑图
- 支持单向/双向边
- 动态边权重（首次通过清障）
- BFS 连通性验证

### 2. 优化算法
- **ILP**: 使用 `javascript-lp-solver` 求解最优分配
- **A***: 欧几里得距离启发式路径规划
- **Hungarian**: 自实现匈牙利算法
- **Greedy**: 工作负载均衡贪心算法

### 3. 可视化技术
- **Mermaid**: 专业甘特图生成
- **ASCII Art**: 终端文本可视化
- **HTML**: 交互式网页显示
- **冲突高亮**: 自动检测并标记时间冲突

### 4. 代码质量
- TypeScript 严格模式
- ESLint 代码规范
- Prettier 自动格式化
- 完整的类型定义

## 📋 已知限制和改进方向

### 当前限制
1. **ILP 求解器**: 对于大规模场景可能无解，自动降级到贪心
2. **冲突解决**: 检测到冲突但不自动重新调度
3. **单元测试**: 尚未实现测试套件
4. **性能优化**: 大规模场景（>20房间）可能较慢

### 未来改进方向
1. **自动冲突解决**: 实现时间偏移调度算法
2. **单元测试**: 使用 Vitest 添加完整测试覆盖
3. **算法优化**: 改进 ILP 约束以提高可解性
4. **多楼层支持**: 扩展到 3D 建筑模型
5. **实时可视化**: WebSocket 实时进度显示
6. **Web 应用**: React + D3.js 交互式界面
