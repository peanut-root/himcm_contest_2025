### 系统架构

```

└───┬──────────────┬──────────────┬─────────────┬────────┘
    │              │              │             │
┌───▼────┐  ┌─────▼────┐  ┌─────▼─────┐  ┌───▼────────┐
│Task    │  │Pathfind  │  │Simulation│  │Validation  │

┌────▼────────────▼──────────────▼─────────────▼────────┐
│              Graph Model (Graphology)                  │
│    Building representation: nodes, edges, rooms        │
└────────────────────────────────────────────────────────┘
```

### 关键设计原则

1. **分层架构**: 清晰的关注点分离（Models → Algorithms → Simulation → CLI）
2. **模块化**: 每个算法可独立替换（ILP/Hungarian/Greedy）
3. **类型安全**: 完全使用 TypeScript，严格类型检查
4. **图论基础**: 基于 graphology 的图表示，支持动态权重
5. **可扩展性**: 易于添加新算法、新约束、新验证规则

## 算法详解

### 2.1 任务分配算法

#### 2.1.1 ILP (整数线性规划) - `src/algorithms/allocation/ilp.ts`

**原理**: 使用 `javascript-lp-solver` 求解 ILP 问题

**决策变量**:
```
x[a][r] ∈ {0, 1}  // 消防员 a 是否检查房间 r
```

**目标函数**:
```
minimize Σ(a,r) x[a][r]  // 最小化总分配数（简化版）
```

**约束条件**:

1. **覆盖约束**（每个房间至少检查一次）:
```
∀r ∈ Rooms:  Σ(a) x[a][r] ≥ 1
```

2. **冗余约束**（冗余房间检查至少两次）:
```
∀r ∈ RedundantRooms:  Σ(a) x[a][r] ≥ 2
```

3. **负载均衡约束**（限制每个消防员的最大任务数）:
```
∀a ∈ Agents:  Σ(r) x[a][r] ≤ avgLoad + 2
其中 avgLoad = ⌈(|Rooms| + |RedundantRooms|) / |Agents|⌉
```

**代码示例**:

```typescript
export async function ilpAllocate(
  agents: Agent[],
  rooms: Room[],
  redundantRooms: string[]
): Promise<AllocationResult> {
  const variables: any = {};
  const constraints: any = {};

  // 创建变量
  for (const agent of agents) {
    for (const room of rooms) {
      const varName = `x_${agent.id}_${room.id}`;
      variables[varName] = {
        agent: agent.id,
        room: room.id,
        cost: 1,
      };
    }
  }

  // 覆盖约束
  for (const room of rooms) {
    constraints[`coverage_${room.id}`] = { min: 1 };
    for (const agent of agents) {
      const varName = `x_${agent.id}_${room.id}`;
      constraints[`coverage_${room.id}`][varName] = 1;
    }
  }

  // 冗余约束
  for (const roomId of redundantRooms) {
    constraints[`redundancy_${roomId}`] = { min: 2 };
    for (const agent of agents) {
      const varName = `x_${agent.id}_${roomId}`;
      constraints[`redundancy_${roomId}`][varName] = 1;
    }
  }

  // 求解
  const model = {
    optimize: 'cost',
    opType: 'min',
    constraints,
    variables,
    ints: { /* 所有变量都是整数 */ },
  };

  const result = solver.Solve(model);
  
  // 提取分配结果
  const assignments = new Map<string, string[]>();
  for (const varName in result) {
    if (varName.startsWith('x_') && result[varName] === 1) {
      // 解析 x_A1_R1 -> agentId=A1, roomId=R1
      const [_, agentId, roomId] = varName.split('_');
      assignments.get(agentId).push(roomId);
    }
  }

  return { assignments };
}
```

**优点**:
- ✅ 找到最优或近似最优解
- ✅ 支持多种约束条件
- ✅ 负载自动均衡

**缺点**:
- ❌ 大规模问题（>50 房间）计算慢
- ❌ 可能无可行解（自动降级到贪心算法）

#### 2.1.2 Hungarian Algorithm - `src/algorithms/allocation/hungarian.ts`

**原理**: 二分图最大匹配（Kuhn-Munkres 算法）

**适用场景**:
- 一对一分配（每个消防员最多分配一个房间）
- 成本矩阵已知

**不适用场景**:
- 冗余检查（需要多对多）
- 负载均衡要求严格

#### 2.1.3 Greedy Algorithm - `src/algorithms/allocation/greedy.ts`

**原理**: 按房间检查时间降序排列，依次分配给当前负载最小的消防员

```typescript
export async function greedyAllocate(
  agents: Agent[],
  rooms: Room[],
  redundantRooms: string[]
): Promise<AllocationResult> {
  const assignments = new Map<string, string[]>();
  const workload = new Map<string, number>();

  // 初始化
  for (const agent of agents) {
    assignments.set(agent.id, []);
    workload.set(agent.id, 0);
  }

  // 按检查时间降序排列房间
  const sortedRooms = [...rooms].sort((a, b) => b.verifyTime - a.verifyTime);

  // 贪心分配
  for (const room of sortedRooms) {
    // 找负载最小的消防员
    let minAgent = agents[0].id;
    let minLoad = workload.get(minAgent)!;

    for (const agent of agents) {
      if (workload.get(agent.id)! < minLoad) {
        minLoad = workload.get(agent.id)!;
        minAgent = agent.id;
      }
    }

    // 分配
    assignments.get(minAgent)!.push(room.id);
    workload.set(minAgent, minLoad + room.verifyTime);
  }

  // 处理冗余房间
  for (const roomId of redundantRooms) {
    // 找到已分配该房间的消防员
    let assignedAgent = '';
    for (const [agentId, rooms] of assignments) {
      if (rooms.includes(roomId)) {
        assignedAgent = agentId;
        break;
      }
    }

    // 分配给负载最小的其他消防员
    let minAgent = agents.find(a => a.id !== assignedAgent)!.id;
    let minLoad = workload.get(minAgent)!;

    for (const agent of agents) {
      if (agent.id !== assignedAgent && workload.get(agent.id)! < minLoad) {
        minLoad = workload.get(agent.id)!;
        minAgent = agent.id;
      }
    }

    assignments.get(minAgent)!.push(roomId);
    const room = rooms.find(r => r.id === roomId)!;
    workload.set(minAgent, minLoad + room.verifyTime);
  }

  return { assignments };
}
```

**优点**:
- ✅ 快速（O(n log n)）
- ✅ 简单易理解
- ✅ 总是有解

**缺点**:
- ❌ 非最优解
- ❌ 可能负载不均衡

### 2.2 路径规划算法

#### 2.2.1 A* Algorithm - `src/algorithms/pathfinding/astar.ts`

**原理**: 使用启发式函数的最短路径算法

**启发式函数**: 欧几里得距离

```typescript
function euclideanDistance(x1: number, y1: number, x2: number, y2: number): number {
  return Math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2);
}
```

**评估函数**:
```
f(n) = g(n) + h(n)
```
- `g(n)`: 从起点到节点 n 的实际代价
- `h(n)`: 从节点 n 到终点的启发式估计
- `f(n)`: 总估计代价

**算法流程**:

```typescript
export function astar(
  graph: Graph,
  startId: string,
  goalId: string
): { path: string[]; cost: number } | null {
  const openSet = new Map<string, AStarNode>();
  const closedSet = new Map<string, AStarNode>();

  // 初始化起点
  const heuristic = euclideanDistance(...);
  openSet.set(startId, {
    id: startId,
    g: 0,
    h: heuristic,
    f: heuristic,
    parent: null,
  });

  while (openSet.size > 0) {
    // 1. 从 openSet 中选择 f 值最小的节点
    let current = findMinFNode(openSet);

    // 2. 到达目标？
    if (current.id === goalId) {
      return reconstructPath(current, closedSet);
    }

    // 3. 将当前节点移到 closedSet
    openSet.delete(current.id);
    closedSet.set(current.id, current);

    // 4. 探索邻居
    for (const neighborId of graph.getNeighbors(current.id)) {
      if (closedSet.has(neighborId)) continue;

      // 计算新的 g 值
      const edgeWeight = getEdgeWeight(graph, current.id, neighborId);
      const tentativeG = current.g + edgeWeight;

      const existingNeighbor = openSet.get(neighborId);
      if (existingNeighbor && tentativeG >= existingNeighbor.g) {
        continue;  // 不是更好的路径
      }

      // 更新或添加到 openSet
      const h = euclideanDistance(...);
      openSet.set(neighborId, {
        id: neighborId,
        g: tentativeG,
        h,
        f: tentativeG + h,
        parent: current.id,
      });
    }
  }

  return null;  // 无路径
}
```

**特性**:
- ✅ 保证找到最短路径（如果启发式是可接受的）
- ✅ 支持动态边权重（清障后权重变化）
- ✅ 比 Dijkstra 更高效（有方向性）

**时间复杂度**: O(E log V)（使用优先队列优化）

### 2.3 验证算法

#### 2.3.1 Coverage Validation - `src/algorithms/validation/coverage.ts`

**验证覆盖率**:

```typescript
export function verifyCoverage(
  rooms: Room[],
  routes: Route[],
  redundantRooms: string[]
): CoverageResult {
  const inspectionCount = new Map<string, number>();

  // 统计每个房间的检查次数
  for (const route of routes) {
    for (const roomId of route.roomsInspected) {
      inspectionCount.set(roomId, (inspectionCount.get(roomId) || 0) + 1);
    }
  }

  // 检查覆盖率
  const missingRooms: string[] = [];
  for (const room of rooms) {
    if ((inspectionCount.get(room.id) || 0) === 0) {
      missingRooms.push(room.id);
    }
  }

  // 检查冗余性
  const insufficientInspections: string[] = [];
  for (const roomId of redundantRooms) {
    if ((inspectionCount.get(roomId) || 0) < 2) {
      insufficientInspections.push(roomId);
    }
  }

  return {
    allRoomsInspected: missingRooms.length === 0,
    missingRooms,
    redundancySatisfied: insufficientInspections.length === 0,
    insufficientInspections,
  };
}
```

#### 2.3.2 Conflict Detection - `src/algorithms/validation/conflicts.ts`

**检测房间访问冲突**（同一房间同时被多个消防员检查）:

```typescript
export function detectRoomConflicts(routes: Route[]): ConflictResult {
  const roomOccupancy = new Map<string, Array<{agentId: string, start: number, end: number}>>();

  // 收集所有房间占用时间段
  for (const route of routes) {
    for (const action of route.actions) {
      if (action.type === 'INSPECT' && action.targetRoom) {
        if (!roomOccupancy.has(action.targetRoom)) {
          roomOccupancy.set(action.targetRoom, []);
        }
        roomOccupancy.get(action.targetRoom)!.push({
          agentId: route.agentId,
          start: action.startTime,
          end: action.endTime,
        });
      }
    }
  }

  // 检测时间重叠
  const conflicts: ConflictingAction[] = [];
  for (const [roomId, occupancies] of roomOccupancy) {
    for (let i = 0; i < occupancies.length; i++) {
      for (let j = i + 1; j < occupancies.length; j++) {
        const a = occupancies[i];
        const b = occupancies[j];

        // 检查时间段重叠
        if (!(a.end <= b.start || b.end <= a.start)) {
          conflicts.push({
            room: roomId,
            agents: [a.agentId, b.agentId],
            timeRange: [Math.max(a.start, b.start), Math.min(a.end, b.end)],
          });
        }
      }
    }
  }

  return {
    noRoomConflicts: conflicts.length === 0,
    conflictingActions: conflicts,
  };
}
```

#### 2.3.3 Metrics Calculation - `src/algorithms/validation/metrics.ts`

**计算性能指标**:

```typescript
export function calculateMetrics(routes: Route[], redundantCount: number): Metrics {
  // Makespan: 最长完成时间
  const makespan = Math.max(...routes.map(r => r.totalTime), 0);

  // 总路径长度
  const totalPathLength = routes.reduce((sum, r) => sum + r.pathLength, 0);

  // 清障效率
  const totalClearanceOps = routes.reduce((sum, r) => sum + r.clearanceOperations, 0);
  const totalEdgeTraversals = routes.reduce((sum, r) => 
    sum + r.actions.filter(a => a.type === 'MOVE').length, 0
  );
  const clearanceEfficiency = totalEdgeTraversals > 0 
    ? totalClearanceOps / totalEdgeTraversals 
    : 0;

  // 冗余覆盖率
  const redundancyCoverage = redundantCount > 0
    ? (实际冗余检查数 / redundantCount)
    : 1.0;

  // 负载均衡（标准差）
  const times = routes.map(r => r.totalTime);
  const avgTime = times.reduce((sum, t) => sum + t, 0) / times.length;
  const variance = times.reduce((sum, t) => sum + (t - avgTime) ** 2, 0) / times.length;
  const stdDev = Math.sqrt(variance);

  return {
    makespan,
    totalPathLength,
    avgPathLength: totalPathLength / routes.length,
    clearanceEfficiency,
    redundancyCoverage: { rate: redundancyCoverage },
    loadBalance: { 
      stdDev, 
      coefficient: avgTime > 0 ? stdDev / avgTime : 0 
    },
  };
}
```

### 3.1 Mission Planner - `src/simulation/planner.ts`

**职责**: 协调整个任务规划流程

```typescript
export class MissionPlanner {
  async planMission(config: MissionConfig): Promise<MissionResult> {
    // 1. 构建图
    const graph = buildGraph(config.building);

    // 2. 分配任务
    const allocation = await ilpAllocate(
      config.agents, 
      config.building.rooms, 
      config.redundantRooms
    );

    // 3. 为每个消防员生成路线
    const routes: Route[] = [];
    for (const agent of config.agents) {
      const assignedRooms = allocation.assignments.get(agent.id) || [];
      const route = await this.generateRoute(
        agent.id, 
        agent.startNode, 
        assignedRooms, 
        graph, 
        config
      );
      routes.push(route);
    }

    // 4. 计算指标
    const metrics = calculateMetrics(routes, config.redundantRooms.length);

    // 5. 验证
    const validation = validate(routes, config);

    return { routes, makespan: metrics.makespan, metrics, validation };
  }

  private async generateRoute(
    agentId: string,
    startNode: string,
    roomIds: string[],
    graph: Graph,
    config: MissionConfig
  ): Promise<Route> {
    const actions: Action[] = [];
    let currentNode = startNode;
    let currentTime = 0;
    let pathLength = 0;

    // 依次访问每个分配的房间
    for (const roomId of roomIds) {
      const room = findRoom(config.building.rooms, roomId);

      // 寻找到房间门的路径
      const pathToRoom = findShortestPath(graph, currentNode, room.doorNode);

      // 添加 MOVE 动作
      for (let i = 0; i < pathToRoom.path.length - 1; i++) {
        const edge = findEdge(graph, pathToRoom.path[i], pathToRoom.path[i + 1]);
        const duration = edge.baseTime + (edge.cleared ? 0 : edge.firstUseClearTime || 0);

        actions.push({
          type: 'MOVE',
          startTime: currentTime,
          duration,
          endTime: currentTime + duration,
          location: pathToRoom.path[i + 1],
          edge: edge.id,
        });

        currentTime += duration;
        pathLength += edge.baseTime;
        edge.cleared = true;

      currentNode = room.doorNode;

      // 进入房间

        type: 'ENTER',
        startTime: currentTime,
        duration: config.timeParameters.enterTime,
        endTime: currentTime + config.timeParameters.enterTime,

        targetRoom: room.id,

      currentTime += config.timeParameters.enterTime;

      // 检查房间

        type: 'INSPECT',
        startTime: currentTime,
        duration: room.verifyTime,
        endTime: currentTime + room.verifyTime,
        location: room.id,
        targetRoom: room.id,

      currentTime += room.verifyTime;

        type: 'EXIT_ROOM',
        startTime: currentTime,
        duration: config.timeParameters.exitTime,
```

### 3.2 Simulation Engine - `src/simulation/engine.ts`

**职责**: 执行仿真，检测运行时冲突

```typescript
export class SimulationEngine {
  simulate(routes: Route[]): SimulationResult {
    const timeline = new Timeline();
    const agentStates = new Map<string, AgentState>();

    // 初始化消防员状态
    for (const route of routes) {
      agentStates.set(route.agentId, {
        currentAction: null,
        location: route.actions[0]?.location || 'start',
        time: 0,
      });
    }

    // 按时间顺序执行所有动作
    const allActions = this.mergeAndSortActions(routes);

    for (const action of allActions) {
      // 更新时间线
      timeline.addEvent(action);

      // 检测冲突
      const conflicts = this.detectRuntimeConflicts(action, agentStates);
      if (conflicts.length > 0) {
        // 插入 WAIT 动作
        for (const conflict of conflicts) {
          this.insertWaitAction(conflict);
        }
      }

      // 更新消防员状态
      this.updateAgentState(agentStates, action);
    }

    return {
      timeline: timeline.export(),
      conflicts: timeline.getConflicts(),
      makespan: timeline.getMaxTime(),
    };
  }
}
```

### 4.1 添加新的分配算法

**步骤**:

1. 在 `src/algorithms/allocation/` 创建新文件，例如 `genetic.ts`

```typescript
// src/algorithms/allocation/genetic.ts
import { AllocationResult } from './greedy.js';
import { Agent } from '../../models/agent.js';
import { Room } from '../../models/building.js';

export async function geneticAllocate(
  agents: Agent[],
  rooms: Room[],
  redundantRooms: string[]
): Promise<AllocationResult> {
  // 1. 初始化种群
  const population = initializePopulation(agents, rooms, redundantRooms);

  // 2. 迭代进化
  for (let generation = 0; generation < MAX_GENERATIONS; generation++) {
    // 2.1 评估适应度
    const fitness = evaluateFitness(population);

    // 2.2 选择
    const selected = selection(population, fitness);

    // 2.3 交叉
    const offspring = crossover(selected);

    // 2.4 变异
    const mutated = mutation(offspring);

    // 2.5 替换
    population = replacement(population, mutated);

    // 2.6 检查终止条件
    if (converged(population)) break;
  }

  // 3. 返回最佳个体
  const best = findBest(population);
  return convertToAllocationResult(best);
}
```

```typescript
// 预计算所有房间门之间的距离
function precomputeDistanceMatrix(graph: Graph, rooms: Room[]): Map<string, Map<string, number>> {
  const distances = new Map<string, Map<string, number>>();

  for (const roomA of rooms) {
    distances.set(roomA.id, new Map<string, number>());

    for (const roomB of rooms) {
      if (roomA.id === roomB.id) {
        distances.get(roomA.id)!.set(roomB.id, 0);
        continue;
      }

      const path = findShortestPath(graph, roomA.doorNode, roomB.doorNode);
      distances.get(roomA.id)!.set(roomB.id, path.cost);
    }
  }

  return distances;
}

// 在分配算法中使用
const distMatrix = precomputeDistanceMatrix(graph, rooms);
const costAB = distMatrix.get('R1')!.get('R2')!;
```

```typescript
export async function ilpAllocateWithTimeout(
  agents: Agent[],
  rooms: Room[],
  redundantRooms: string[],
  timeoutMs: number = 10000
): Promise<AllocationResult> {
  return Promise.race([
    ilpAllocate(agents, rooms, redundantRooms),
    new Promise((_, reject) => 
      setTimeout(() => reject(new Error('ILP timeout')), timeoutMs)
```

## 常见问题

### Q1: ILP 求解器报错 "infeasible"

**原因**: 约束条件冲突，无可行解

**解决**:
1. 检查消防员数量是否足够（需要 >= ⌈冗余房间数/2⌉）
2. 放宽负载均衡约束（增加 `avgLoad + 2` 的容差）
3. 检查图连通性（所有房间是否可达）

### Q2: 路径规划返回 null

**原因**: 起点和终点不连通

**解决**:
```typescript
// 先检查连通性
if (!graph.hasPath(from, to)) {
  console.error(`No path exists between ${from} and ${to}`);
  // 检查图结构是否正确
}
```

### Q3: 性能慢，makespan 很大

**原因**: 
- 任务分配不均衡
- 路径规划次优
- 清障时间过长

**解决**:
1. 尝试不同的分配算法
2. 调整 ILP 约束（更严格的负载均衡）
3. 优化建筑布局（减少瓶颈边）
4. 预先清障关键路径

### Q4: 如何添加新的节点类型？

**步骤**:
1. 修改 `Node.kind` 类型定义
```typescript
export type NodeKind = 'CORRIDOR' | 'DOOR' | 'EXIT' | 'ELEVATOR' | 'STAIR';
```

2. 在路径规划中处理新类型的权重
```typescript
function getEdgeWeight(edge: Edge, fromNode: Node, toNode: Node): number {
  let weight = edge.baseTime;

  // 电梯额外等待时间
  if (toNode.kind === 'ELEVATOR') {
    weight += 15;  // 假设等待电梯需要 15 秒
  }

  // 楼梯额外时间（基于楼层差）
  if (toNode.kind === 'STAIR') {
    const floorDiff = Math.abs((toNode as any).floor - (fromNode as any).floor);
    weight += floorDiff * 10;  // 每层楼梯 10 秒
  }

  return weight;
}
```
